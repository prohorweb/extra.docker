# Journal

This folder contains chronological records of all changes made during migration.
Each entry describes:
- what was changed
- why
- deviations from the plan
- next steps

## Format

Каждый день — новый файл.

Имя файла: `YYYY-MM-DD.md`

Примеры:
- `2026-06-09.md` — запись за сегодня
- `2026-06-10.md` — запись за завтра

Внутри каждого файла — свободное описание по шаблону:
- Что сделано
- Проблемы и их решения
- Статус
- Следующие шаги
