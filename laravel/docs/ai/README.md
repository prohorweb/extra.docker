# docs/ai — AI Operational Layer

## Порядок чтения:
1. **CURRENT_STATE.md** → что делаем сейчас
2. **TASKS.md** → список задач с приоритетами
3. **DECISION_LOG.md** → прошлые решения (ADR)
4. **ARCHITECTURE.md** → Yii2 vs Laravel mapping

## Режимы AI:
- **ANALYST** — только чтение, анализ, планирование
- **EXECUTOR** — минимальные изменения, max 3 файла за коммит
