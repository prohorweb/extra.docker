# docs/ai — AI Операционный слой

Обязательный порядок чтения в начале каждой сессии:

1. **CURRENT_STATE.md** — что сделано, что в работе, следующие шаги
2. **TASKS.md** — список задач с приоритетами
3. **SYSTEM.md** — роли, принципы, запрещённые действия
4. **MIGRATION_RULES.md** — жёсткие ограничения и маппинг Yii2 → Laravel

Дополнительно (по необходимости):
- **ARCHITECTURE.md** — сравнение архитектур Yii2 vs Laravel 12
- **DECISION_LOG.md** — принятые решения (ADR)
- **PROTOCOL.md** — формат ответов AI
- **RUNTIME.md** — pipeline выполнения задач
- **context/yii2.md** — справочник по Yii2
- **context/laravel12.md** — справочник по Laravel 12
- **domains/*.md** — контекст конкретного домена (home, user, map…)

## Иерархия источников истины

| Приоритет | Источник | Что содержит |
|-----------|----------|--------------|
| 1 (высший) | `sessions/` | Реальное состояние системы |
| 2 | `ai/CURRENT_STATE.md` | Живой статус миграции |
| 3 | `migration/` | Плановая стратегия |
| 4 | `ai/` | Правила и ограничения |

Если есть конфликт — сессии и CURRENT_STATE побеждают.

## Режимы работы

| Режим | Когда | Что разрешено |
|-------|-------|---------------|
| **ANALYST** | анализ, планирование, аудит | только чтение + запись в `ai/*.md` |
| **EXECUTOR** | реализация, миграция, создание файлов | запись в `app/`, `resources/`, `routes/`, `database/` + `ai/*.md` |
